# 自定义辅助码

把自己的辅助码方案放进本目录，在设置窗口「辅助码」页点「刷新方案」（或重新打开设置窗口）后，就能在双拼和全拼方案下拉框里选到它。修改正在使用的方案文件后，要切换一次方案或重启输入法才会生效。
升级安装会保留本目录里的文件；卸载输入法时会随数据目录一起删除，请自行备份。

## 文件要求

- 扩展名必须是 `.txt`，编码必须是 UTF-8（带不带 BOM 都可以）。
- 每行一个字：`字=辅助码`，辅助码取等号后的前两个小写字母（`a`–`z`），例如 `妈=nm`。
- 以 `#` 开头的行是注释，会被忽略。
- 方案在配置里记作 `custom/<文件名去掉 .txt>`，改文件名等于换了一个方案；当前选中的方案文件被删掉或改名后，会回退到蓝天小雨点。

## 方案名称

设置里默认按文件名显示。想换个名字，在文件开头加上注释：

```text
# name: 我的辅助码
# name_en: My Helpcode
阿=ek
锕=jk
```

- `name` 是中文名，设置页显示它；`name_en` 是英文名。
- 只写其中一个时，另一个用同一个名字；两个都不写就用文件名。
- 冒号用半角 `:` 或全角 `：` 都行。名称注释只在文件开头（第一个非注释行之前）生效。
