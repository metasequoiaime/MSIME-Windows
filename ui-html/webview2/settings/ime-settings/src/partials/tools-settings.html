实用功能
剪贴板管理
开启后，复制过的文本会显示在表情面板的剪贴板分页中。关闭后立即清空已保存的记录，且只记录文本类型。
快捷短语(K 模式)
中文模式下按 Shift+K，再输入编码即可调用快捷短语
编码只能包含英文字母；触发键 K 不属于编码内容。批量导入格式为：编码<Tab>短语<Tab>权重（兼容无权重的两列文件）

日期与时间快捷输入(T 模式)
中文模式下按 Shift+T，再输入 rq / riqi / date 可输入当前日期；输入 sj / shijian / time 可输入当前时间；输入 xq / xingqi / week 可输入当前星期。
Unicode 便捷录入(U 模式)
中文模式下按 Shift+U，再输入 Unicode 十六进制码位（可带 +，如 4e00 / +1f600）。空格上屏；Shift+数字选词。
数字转换(V 模式)
全拼下直接输入 v 加数字（如 v123456.78），或按 Shift+V 再输入数字，候选给出人民币大写金额、中文大写 / 小写读法、逐位读法和 123,456 / 12,3456 两种分节写法。双拼下 v 是声母键，只能用 Shift+V。空格上屏；Shift+数字选词。
Emoji 快捷输入(E 模式)
中文模式下按 Shift+E，再输入全拼 / 简拼 / 双拼 / 英文关键词即可输入 emoji。例如 xiaolian、xl、xnlm（小鹤双拼）、laugh。空格上屏；数字选词。
颜文字快捷输入(M 模式)
中文模式下按 Shift+M，再输入全拼 / 简拼 / 双拼 / 英文关键词即可输入颜文字。例如 haixiu、hx、zai xiang、zx、kiss。空格上屏；数字选词。
超级简拼(J 模式)
中文模式下按 Shift+J，之后输入的每个字母都作为简拼检索词库。全拼如 nh → 你好；双拼会按当前方案转换声母，例如小鹤 nu → n'sh（你说），与 ns → n's 不同。空格上屏；数字选词。调频规则与全拼 / 双拼相同。
临时英文(Y 模式)
中文模式下按 Shift+Y，之后输入的字母按英文处理，不会当作拼音。空格上屏当前输入；数字可选英文词库中的单词。上屏后自动回到中文输入。
临时日语(R 模式)
中文模式下按 Shift+R，之后输入的字母按日语罗马字处理。空格上屏首选，数字可选其他日语候选。上屏后自动回到中文输入。
